# Site notes
- **News:** add a file `_posts/YYYY-MM-DD-short-title.md` with front matter `title:` and optional `category:` (Talk, Paper, Software...), then write the text below it.
- **Publications:** add an entry at the top of `_data/publications.yml`. Optional `image: /assets/journals/xyz.jpg` replaces the generated journal tile.
- Push to `main`; GitHub Pages rebuilds in ~1 min.
